# Asteroids

Аркадна гра для браузера: ухиляйся від астероїдів, збирай кристали, пройди 25 рівнів кампанії або встанови рекорд у режимі виживання.

Це веб-версія курсової роботи з ООП. Оригінал був написаний на C# / WinForms і повністю переписаний на **TypeScript + Canvas 2D**. Гра працює на комп'ютері (клавіатура) і на телефоні (сенсорний джойстик).

## Запуск локально

```bash
npm install
npm run dev       # дев-сервер з hot reload
npm run build     # продакшн-збірка в dist/
npm run preview   # перегляд зібраної версії
```

## Деплой

У `dist/` лежать звичайні статичні файли, тому їх можна викласти на будь-який хостинг.

- **GitHub Pages**: workflow `.github/workflows/deploy.yml` збирає й публікує гру при кожному push у `main`. Один раз потрібно ввімкнути: *Settings → Pages → Source: GitHub Actions*.
- **Vercel / Netlify**: імпортуй репозиторій. Build command: `npm run build`, output directory: `dist`.
- **itch.io**: заархівуй вміст `dist/` у zip і завантаж як HTML-гру.

## Що змінилось порівняно з WinForms-версією

**Геймплей**
- 25 рівнів замість 5, поділених на 5 секторів.
- 11 типів небезпек, що з'являються поступово:
  - комети з попередженням-траєкторією;
  - самонавідні «мисливці»;
  - рикошетні астероїди;
  - «стіни» з проходом;
  - метеоритний дощ;
  - туман;
  - міни з ланцюговими вибухами;
  - сонячний вітер;
  - чорні діри;
  - лазерні бар'єри;
  - бос-астероїд.
- Кристали й зірки (до 3 за рівень), бонуси: щит, заряди заморозки й форсажу.
- 11 літаків різної форми, кожен зі своєю фічею: таран, магніт, подвійний ривок, ударна хвиля, друге життя, антигравітація тощо.
- Валюта **коінс**. Як заробити:
  - кристали: +5 за кожен;
  - проходження рівня: база плюс бонус за зірки, за перше проходження вдвічі більше;
  - час у виживанні;
  - щоденна нагорода: серія з 7 днів, від 50 до 500 коінс.
- За коінс в ангарі купуються нові літаки.
- Відлік 3-2-1 перед стартом і підказка про нову небезпеку рівня.
- Виживання: складність росте кожні 10 с, нові небезпеки відкриваються з часом, топ-5 результатів.

**Виправлені баги**
- Тертя множилось на кожному кадрі без урахування `dt`: швидкість літака залежала від FPS і реально була ~100 px/s замість 320.
- Програш у кампанії скидав *увесь* прогрес. Тепер можна просто повторити рівень.
- Рівні тривали лише `level * 10` секунд (перший рівень — 10 с).
- Астероїди з'являлись уже всередині екрана (відступ 10 px при радіусі спрайта до 42 px).
- Астероїд міг з'явитись впритул до літака, притиснутого до краю.
- Клавіші «залипали» після втрати фокусу вікна; гра не ставала на паузу.
- Назви скінів (`Red/Blue/Green`) не відповідали картинкам.
- Фіксований крок фізики (1/120 с): швидкі об'єкти не «проскакують» крізь літак.

**Інтерфейс**
- Анімоване меню з живим фоном, навігація з клавіатури, модальні вікна, HUD з таймером, прогресом і перезарядкою навичок.
- Українська та англійська мови, гучність, тряска екрана, скидання прогресу.
- Звуки синтезуються через WebAudio, тож аудіофайли не потрібні.
- Адаптивна верстка й сенсорне керування.

## Структура

```
src/
  core/      математика, ресурси, введення, звук, збереження, i18n
  game/      Game (ігровий менеджер), рівні, літаки
    entities/  Entity → Asteroid → HomingAsteroid / BouncingAsteroid / Comet / BlackHole / BossAsteroid,
               Mine, LaserGate, Player, Pickup
    systems/   SkillSystem, ParticleSystem, Starfield
  ui/        екрани (Screen → MainMenu, LevelSelect, Hangar, …), модалки, HUD
  app/       App: canvas, ігровий цикл, перемикання екранів
```

Усі 11 літаків намальовані кодом на Canvas (`src/game/PlaneArt.ts`): металеві градієнти, кабіни, сопла, навігаційні вогні й анімовані деталі. Статичний корпус кешується в offscreen-canvas.

Шрифт логотипа — [Bungee](https://github.com/djrrb/Bungee) (SIL OFL 1.1).
